# Практическая работа №2: работа с файлами в Java

Проект полностью реализует четыре задания практической работы.

## Задание 1 — чтение и запись через java.nio

Главный класс: `practice2.text.TextFileNioMain`.

Программа создаёт UTF-8 файл `data/text/sample.txt`, записывает в него три
строки через `Files.write`, затем читает через `Files.readAllLines` и выводит
содержимое. Необязательный аргумент задаёт другой путь к файлу.

## Задание 2 — сравнение копирования файла

Главный класс: `practice2.copy.FileCopyBenchmarkMain`.

По умолчанию создаётся файл размером 100 МБ и копируется четырьмя способами:

1. `FileInputStream` и `FileOutputStream`;
2. `FileChannel.transferTo`;
3. `Apache Commons IO FileUtils.copyFile`;
4. `Files.copy`.

Для каждого способа выводятся время и примерный пиковый рост heap-памяти.
После копирования проверяются размер и 16-битная checksum каждой копии.
Дополнительно печатаются самый быстрый и самый экономный по heap способ в
конкретном запуске. Результаты зависят от диска, кэша ОС, JVM и фоновой
нагрузки, поэтому это учебный benchmark.

Аргументы:

```text
<размер в МБ> <каталог результатов>
```

Быстрый пример:

```text
5 data/copy
```

Для выполнения условия задания запускайте без аргументов или с размером 100.

## Задание 3 — 16-битная контрольная сумма

Главный класс: `practice2.checksum.ChecksumMain`.

`ChecksumCalculator` читает файл через `FileChannel` в `ByteBuffer`, объединяет
байты в 16-битные слова и применяет XOR. Для файла нечётной длины последний
байт считается старшим байтом последнего слова. Результат выводится как
четырёхзначное шестнадцатеричное число.

Аргумент — путь к файлу. Без аргументов используется файл первого задания:

```text
data/text/sample.txt
```

## Задание 4 — WatchService

Главный класс: `practice2.watch.DirectoryWatcherMain`.

По умолчанию наблюдается каталог `data/watched`. Сервис отслеживает создание,
изменение и удаление файлов. При изменении выводятся добавленные и удалённые
строки с префиксами `+` и `-`.

После события удаления прочитать файл уже невозможно. Поэтому при создании и
каждом изменении программа заранее сохраняет его размер, строки и checksum, а
при удалении выводит последнее сохранённое состояние. Существующие файлы
сканируются до начала цикла событий, поэтому первое изменение тоже сравнивается
с предыдущим содержимым.

Аргументы:

```text
<каталог> <максимальное число событий>
```

Ноль событий означает бесконечное наблюдение. Остановка — `Ctrl+C`.

## Сборка и тесты

Проект использует Maven и зависимость `commons-io:commons-io:2.13.0`.

```powershell
mvn clean test-compile
mvn -q exec:java -Dexec.mainClass=practice2.PracticeTwoTest -Dexec.classpathScope=test
```

В IntelliJ IDEA откройте `second/pom.xml` как Maven-проект. Все четыре главных
класса также доступны в готовых конфигурациях запуска.
