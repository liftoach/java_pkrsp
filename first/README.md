# Практическая работа №1: многопоточность в Java

Проект полностью закрывает три задания практической работы.

## Задание 1 — обработка массива

Создаётся массив из 10 000 случайных чисел. Для функций `SUM`, `MAX` и
`MIN` доступны четыре реализации:

1. последовательная;
2. ручные потоки `Thread`;
3. `ExecutorService` и `Future`;
4. `ForkJoinPool` и `RecursiveTask`.

После каждой операции сложения или сравнения выполняется `Thread.sleep(1)`.
Программа проверяет одинаковость результатов и сравнивает среднее время и
примерный пиковый рост heap-памяти JVM.

Главный класс: `practice.Main`.

Аргументы:

```text
<SUM|MAX|MIN> <число потоков> <число повторений> <размер массива>
```

Для задания достаточно запустить без аргументов: по умолчанию используются
`MAX`, доступное число процессоров, один запуск и 10 000 элементов.

Пример:

```text
MAX 4 1 10000
```

Соответствие варианту по формуле `номер в списке % 3`:

- остаток `1` — `SUM`;
- остаток `2` — `MAX`;
- остаток `0` — `MIN`.

## Задание 2 — асинхронное вычисление квадрата

Главный класс: `practice.async.AsyncSquareMain`.

Введите несколько целых чисел подряд. Каждая задача получает случайную
задержку от 1 до 5 секунд и выполняется в пуле из пяти потоков. Ввод следующего
числа доступен сразу, а готовые результаты печатаются отдельным потоком.
Команда `exit` прекращает ввод и дожидается всех принятых запросов.

## Задание 3 — генератор и обработчики файлов

Главный класс: `practice.files.FileProcessingMain`.

Генератор создаёт файлы типов `XML`, `JSON` и `XLS` размером от 10 до 100 с
задержкой 100–1000 мс. Главная `BlockingQueue` имеет вместимость 5. Диспетчер
направляет каждый файл обработчику нужного типа, обработка длится
`размер * 7 мс`. Блокирующие очереди обеспечивают потокобезопасность и не
расходуют CPU во время ожидания, а итоговая проверка подтверждает, что ни один
файл не потерян.

Необязательный аргумент — количество генерируемых файлов, по умолчанию 12:

```text
20
```

## Компиляция и тесты

Требуется JDK 17 или новее. Из папки `first`:

```powershell
New-Item -ItemType Directory -Force out/production | Out-Null
javac --release 17 -encoding UTF-8 -d out/production `
  (Get-ChildItem src/main/java -Recurse -Filter *.java).FullName

javac --release 17 -encoding UTF-8 -cp out/production -d out/test `
  (Get-ChildItem src/test/java -Recurse -Filter *.java).FullName

java -cp "out/production;out/test" practice.ArrayProcessorTest
```

Из IntelliJ IDEA каждый из трёх главных классов можно запускать зелёной
стрелкой около метода `main`.
